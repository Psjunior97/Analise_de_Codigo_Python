# Analise_de_Codigo_Python

📊 Apresentação: Atividade Prática de Programação em Python

🎯 Objetivo Geral da Atividade
Esta atividade prática teve como objetivo desenvolver soluções automatizadas para problemas do cotidiano acadêmico e comercial. Foram criados scripts focados em manipulação de dados, cálculos estatísticos e tomada de decisões automatizada, aplicando os conceitos fundamentais da programação estruturada.

💻 Resumo dos Scripts Desenvolvidos

Script 2: Análise de Sequência Numérica
* O que faz: Recebe uma quantidade indefinida de números inteiros positivos do usuário e, ao final, gera um relatório estatístico completo sobre esses dados.
* Conceitos Computacionais Abordados:
  * Coleções de Dados: Uso de Listas ([]) e do método .append() para armazenar dados dinamicamente na memória.
  * Estruturas de Repetição: Uso do while True e break para criar um fluxo de entrada contínuo com critério de parada (digitar 0).
  * Funções Nativas do Python: Aplicação de sum(), len(), max() e min() para evitar cálculos manuais complexos.
  * Operadores Matemáticos: Uso do operador de módulo (%) para descobrir o resto da divisão e identificar números pares.

Script 3: Sistema de Descontos
 * O que faz: Calcula automaticamente o preço final de uma compra aplicando descontos baseados na categoria do cliente (VIP, Regular ou Comum).
 * Conceitos Computacionais Abordados:
   * Modularização (Funções): Criação de funções personalizadas com passagem de parâmetros e retorno de valores (return), organizando melhor o código.
   * Tratamento de Strings: Uso do método .upper() para converter textos em maiúsculas, tornando o sistema à prova de erros de digitação do usuário.
   * Estruturas de Decisão Encadeadas: Uso de if, elif e else para avaliar múltiplas condições de desconto de forma eficiente.

Script 4: Cadastro e Classificação de Alunos
* O que faz: Registra o nome e a nota de vários alunos, classifica o desempenho de cada um em categorias (Excelente, Bom, Regular, Insuficiente) e exibe um relatório formatado no final.
* Conceitos Computacionais Abordados:
  * Estruturas de Dados Compostas: Combinação de Listas com Dicionários ({}) para modelar dados complexos do mundo real (um dicionário chave-valor para cada aluno, agrupados dentro de uma grande lista).
  * Laço de Repetição Condicional e Iterativo: Uso do while para a fase de cadastro e do for para varrer a lista e gerar o relatório final.
